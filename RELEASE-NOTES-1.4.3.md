# ScootPit BMS 1.4.3

## Komplettes Fahrtenbuch importieren
- Einen Ordner mit ScootPit-Fahrten auswählen; JSON-Metadaten, CSV-Aufzeichnungen und vorhandene GPX-Dateien werden gemeinsam übernommen.
- Unterordner werden durchsucht. Die Fahrten werden dem aktiven Scooter-Profil zugeordnet; bestehende Dateien bleiben erhalten und Duplikate werden übersprungen.
- Die Fahrtenbuchansicht **Alle** zeigt importierte Fahrten unabhängig von ihrem Alter.
- Der Import ist auf 5.000 Dateien, 32 MB je Datei und 512 MB insgesamt begrenzt.
- Der bisherige Import einzelner CSV- oder GPX-Fahrten bleibt verfügbar.

## Installation
Die signierte APK aktualisiert die bestehende Installation. App-ID und Signierschlüssel bleiben gleich; Android-Versionscode 22.
